Testing Strategy

This test validates that existing nodes stay fixed when new nodes are added to a d3-force layout.

  • Initial State: 5 nodes connected in a star pattern
  • Add Nodes (Pinned): Existing nodes are fixed with fx/fy, new nodes are positioned by force
  • Add Nodes (Unpinned): All nodes repositioned (shows the problem)
